# Hetvi Sheth – Portfolio

A premium, dark‑navy + teal themed portfolio showcasing my AI/ML, data‑analytics, and full‑stack development projects. Built with vanilla HTML, CSS, and Vite, deployed on Vercel.

- **Live demo:** https://portfolio-f8r396tf2-hetvi16-05s-projects.vercel.app (alias https://portfolio-liart-pi-28.vercel.app)
- **Tech stack:** HTML, CSS (glassmorphism, DM Serif Display + DM Sans), JavaScript (Vite), SVG charts, Vercel CI/CD.
- **Features:** Left navigation, project grid, learning footprint visual, AR​CANUM glass prompt, editorial recommendations.
- **Setup:**
  ```bash
  npm install -g vercel   # if not installed
  npm ci && npm run dev   # local dev server
  vercel --prod --yes      # deploy to Vercel
  ```

The `public/` folder (containing confidential PDFs) has been removed from the repository and added to `.gitignore`.
